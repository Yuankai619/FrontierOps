Quick Start

研究者只需對 Coding Agent 說 Setup、Config、Discover、Briefing。以下是第一次使用時要準備的環境。

Quick Start四個使用步驟AutoSci 範例frontier.yaml指令參考輸出與紀錄

準備環境

需要 uv >=0.12.20, <0.14。若要建置 OpenSlide，還需要 Node.js 與 npm。先進入你的研究專案目錄，再在 Agent 裡安裝 FrontierOps plugin。

Claude Code

claude plugin marketplace add Yuankai619/FrontierOps
claude plugin install frontierops@frontierops

Codex CLI

codex plugin marketplace add Yuankai619/FrontierOps
codex plugin add frontierops@frontierops

GitHub Copilot CLI

copilot plugin install Yuankai619/FrontierOps:plugins/frontierops

這些是宿主的 plugin 命令。此次端到端範例在 Codex 使用本機 checkout；Claude／Copilot 的遠端安裝尚未實測。宿主語法可查 Claude、Codex、Copilot CLI 文件。

第一次對 Agent 說

setup

Setup 以目前目錄為研究 workspace，檢查環境並建立 frontier.yaml 與 frontier_output/。它不會同步論文。若目前目錄不是研究專案，Agent 才會問你要使用哪裡。

plugin 只提供 Skill。正式安裝時 Setup 執行 uv tool install git+https://github.com/Yuankai619/FrontierOps.git，Python 套件安裝在 uv tool 環境，研究 workspace 只有設定、素材與輸出，沒有 FrontierOps 原始碼。開發者在 repo checkout 使用 uv sync --locked 與 uv run --locked frontier；套件從該 checkout 的虛擬環境執行，也不會複製到測試 workspace。

接著做什麼

最短路徑是 config <arXiv PDF URL>、discover、選取論文後 briefing。詳見四個使用步驟，或直接看AutoSci 對話範例。
