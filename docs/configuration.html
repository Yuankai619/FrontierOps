frontier.yaml

這是唯一生效的設定。Agent 可以替你寫；需要手動檢查時，用下列欄位對照。未知欄位會驗證失敗，未指定值保留 schema 預設。

Quick Start四個使用步驟AutoSci 範例frontier.yaml指令參考輸出與紀錄

單篇 PDF 的設定

schema_version: "0.1"
project:
  id: autosci
  name: AutoSci
  language: en
sources:
  local_library:
    enabled: true
    roots: [data/library]
profile:
  topics:
    - id: research-agents
      description: Research agents and persistent memory
      weight: 1.0
ranking:
  gates: []
  features:
    citation: {enabled: false, weight: 0.0}
brief:
  target_duration_seconds: 300
  maximum_seconds_per_development: 300
  outputs: [html, slides]
rendering:
  video: {enabled: false}

roots 以 YAML 所在資料夾為基準。本地 PDF 沒有可靠引用數時，關閉 citation 特徵比硬設門檻合理。完整預設與型別請執行 frontier schema config --format json。

各區塊做什麼

區塊設定與後果
project名稱、輸出語言、內部 workspace_dir（預設 .frontier）、公開 output_dir（預設 frontier_output）。語言欄位不會自動翻譯原文。
sources啟用本地庫、arXiv、Semantic Scholar 或 OpenReview。只填 URL 仍需選對來源；Config Skill 可將指定 arXiv PDF 存入本地庫供全文與圖像分析。
trackingscholars 與 venues 使用來源穩定 ID；同名學者須確認。Google Scholar live adapter 尚未實作。
profiletopics[].description/weight 與 keywords.include/exclude 表示研究興趣；關鍵字只輔助初篩。
rankinggates 決定可否入選；features.*.weight 對合格論文排序。分數不是品質、可信度或接受機率。
synctrigger_mode: manual，以最近成功同步的 cursor 比較。來源失敗可選 fail 或 partial。
brieftarget_duration_seconds 預設 300，可自訂；outputs 選 HTML、slides、video；maximum_developments 限一次選幾篇。
review控制缺證據、無來源數字、重複等是否阻擋；不能語意判斷主張是否真的受原文支持。
rendering.video預設關閉；開啟前需備旁白服務並同意可能的費用。這次 AutoSci 不測影片。

持續追蹤研究主題

sources:
  openalex: {enabled: true, mode: live, max_results: 200}
profile:
  topics:
    - id: ai-agent-harness
      description: AI agent harness and execution environments
      search:
        providers: [openalex]
        query: '"AI agent" AND harness'
        published_from: 2025-01-01
        published_to: 2025-12-31

下次調整年份時保留相同主題 ID。max_results 是每個主題的上限；若結果截斷，不可聲稱已完整找出新增論文。alphaXiv 另需啟用 sources.alphaxiv，並在 search.keywords 設定 3–4 個詞。API key 只放環境變數，不放 YAML。

Gate 和權重

Gate 先回答「能不能進候選清單？」權重再決定入選後的排列。新預印本往往沒有 citation count，不應套固定最低引用數；可以用 on_fail: warn 或新論文豁免。

ranking:
  gates:
    - id: citations
      type: citation
      minimum_count: 3
      exempt_if_age_days_lte: 90
      on_fail: warn

候選設定檔

.frontier/config-drafts/*.candidate.yaml 是 Config Skill 做 validate 和 diff 用的提案；它不會被 Sync 讀取。確認後 Agent 才把變更套用到 frontier.yaml。保留候選檔有助於追溯修改，但日常只需看 active YAML。
