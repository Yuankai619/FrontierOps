FrontierOps 是供 Claude Code、Codex 等既有 Coding Agent 使用的研究簡報 Harness。研究者決定要追蹤什麼、何時檢查更新；Agent 用它整理原文證據，做出可回查的論文解說。

開始使用 ↗ 看四個使用步驟 →

先回答論文在做什麼。

論文清單只告訴你「有什麼」。FrontierOps 的目標是讓研究者迅速看懂「為什麼做、怎麼做、證據支持到哪裡、還有哪些限制」。每個關鍵主張都能回到原文頁面。

它不在背景自行計時搜尋。只有你要求 Discover 時才同步；新結果會與上次成功同步比對，過往紀錄仍保留。

研究者看到四個動作。

  1. 01

    Setup

    建立工作區，檢查環境，產生可編輯的設定檔。

  2. 02

    Config

    用自然語言描述研究範圍；Agent 驗證並套用規則。

  3. 03

    Discover

    你要求時才同步，並展示新增論文與篩選理由。

  4. 04

    Briefing

    核對原文後，產生可互動的解說與簡報。

底層 Build、Sync、Rank、Brief、Review、Render 保留各階段紀錄，供 Agent 除錯；研究者不必逐段操作。

互動 HTML

按研究問題切換段落，展開證據，查看論文圖與 PDF 原頁。

OpenSlide

保留可編輯的投影片原始專案；建置後可在瀏覽器展示。

影片預覽

可選功能；需另外啟用旁白服務。本次 AutoSci 範例只驗收 HTML 與 slides。
