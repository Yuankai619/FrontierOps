AutoSci 範例

這是一段研究者與 Agent 的對話，不是給 Agent 的長篇驗收腳本。論文是 AutoSci，目前仍為 arXiv 預印本。

Quick Start四個使用步驟AutoSci 範例frontier.yaml指令參考輸出與紀錄

1. 建立工作區

setup

Agent 回報：已建立 frontier.yaml，來源尚未啟用。若你不在預期的研究目錄，Agent 先問「要用哪個資料夾？」。

2. 指定論文

config https://arxiv.org/pdf/2605.31468

Agent 取得 PDF，確認標題、作者、機構與日期，寫入本地庫與 sidecar；顯示設定差異後套用。若要改需求，也可補一句：「只做 HTML 和 slide，不做影片，先不要 citation 門檻」。

3. 查看新論文

discover

Agent 報告首次 Sync 新增 1 篇，提供本機 Discover 頁。你在頁面勾選 AutoSci 並按「儲存選取」。再次 Discover 會報新增 0 篇，不會把它說成新論文。

4. 產生解說

briefing

Agent 讀取剛才選取的 AutoSci，核對論文圖、方法與案例結果。如果你想調整，可以直接說「加強 SciFlow 和 SciDAG 的機制，結果要交代評估限制」。

原始 deterministic 草稿可能抓到附錄句子；Review 只能檢查來源 ID、數字與精確引句等，無法保證語意正確。Agent 必須實際看原文。完整實跑紀錄列出每步輸入、輸出與已知問題。
