The YAML names environment variables; it never contains secret values. The process running the Python harness must receive those variables.

Provider requirements

SourceAuthentication used by this harness
OpenAlexOptional API key named by sources.openalex.api_key_env; otherwise keyless basic queries.
alphaXiv MCPAPI key required for live headless access; default environment variable ALPHAXIV_API_KEY.
OpenReview API 2Existing token or username plus password; environment variable names are configured under sources.openreview.
Semantic ScholarOptional API key named by sources.semantic_scholar.api_key_env.
arXiv / local libraryNo API key for the current adapter.

See the configuration reference for every source field. Never commit keys, passwords, token files, or a populated .env to this repository.
